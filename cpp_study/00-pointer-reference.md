## *와 & 쓰임

### 용도별 이름 

 코드  │                영어 명칭                 │      한국어 명칭       │        하는 일        │
├───────┼──────────────────────────────────────────┼────────────────────────┼───────────────────────┤

├───────┼──────────────────────────────────────────┼────────────────────────┼───────────────────────┤
│ *p    │ dereference operator (또는 indirection   │ 역참조 연산자 (간접    │ 주소로 찾아가 값을    │
│       │ operator)                                │ 연산자)                │ 꺼내요                │
├───────┼──────────────────────────────────────────┼────────────────────────┼───────────────────────┤
│ int*  │ pointer (pointer declarator)             │ 포인터 (선언)          │ 주소를 담는 변수의    │

├───────┼──────────────────────────────────────────┼────────────────────────┼───────────────────────┤

├───────┼──────────────────────────────────────────┼────────────────────────┼───────────────────────┤

│       │ operator)                                │                        │

### 포인터

- 메모리(RAM)
    - 아주 긴 사물함 줄. 사물함마다 번호(주소)가 붙어 있음

주소:   ...  0x...2fc   0x...300   0x...304  ...
       ┌────────────┬──────────┬──────────┐
내용:   │     42     │    ...   │    ...   │
       └────────────┴──────────┴──────────┘
            ↑
          변수 x

int x = 42;라고 쓰면 컴퓨터가 빈 사물함 하나를 골라 x라는 이름을 붙이고, 안에 42를 넣어요. 우리는 이름(x)으로 부르지만, 컴퓨터는 실제로 주소로 찾아가요.

- 포인터 : 주소를 담는 변수
    - 일반 변수: 사물함 안에 42 같은 값이 들어 있어요.
    - 포인터: 사물함 안에 **"2fc번 사물함"**이라고 적힌 쪽지가 들어 있어요.

int x = 42;      // x 사물함에 42를 넣음
int* p = &x;     // p 사물함에 "x의 주소"를 적은 쪽지를 넣음

   p                         x
┌──────────────┐          ┌──────┐
│ 0x7fff...2fc │ ───────▶ │  42  │  (주소 0x7fff...2fc)
└──────────────┘          └──────┘
   "저기 있어요"              실제 값

### 역참조

포인터에 적힌 주소로 찾아가서 그 안의 값을 보거나 바꾸는 것이에요. 코드로는 포인터 앞에 *를 붙여요.

### 포인터랑 참조 차이

둘 다 원본을 복사하지 않고 가리키는 방법.
- 포인터 = 주소를 담는 변수. 다른 주소로 고쳐 쓸 수 있고, 비워둘 수도 있음
- 참조 = 원본에 붙인 두 번째 이름표. 한 번 붙이면 떼거나 옮길 수 없음

### 코드로 비교

기본 예시

int x = 42;

int* p = &x;    // "int 포인터 p에 x의 주소를 넣는다" → "p가 x를 가리킨다"
*p = 100;       // "p가 가리키는 것에 100을 넣는다"  → x == 100
int y = *p;     // "y에 p가 가리키는 값을 넣는다"    → y == 100

int& r = x;     // "int 참조 r은 x" → "r은 x의 별명"
r = 7;          // "r(= x)에 7을 넣는다"              → x == 7

표로 정리

┌──────────────┬──────────────────────────────────────────────┬──────────────────────────┐
│     코드     │                 이렇게 읽기                  │           결과           │
├──────────────┼──────────────────────────────────────────────┼──────────────────────────┤
│ &x           │ "x의 주소"                                   │ 0x7fff...2fc 같은 주소값 │
├──────────────┼──────────────────────────────────────────────┼──────────────────────────┤
│ int* p       │ "int 포인터 p"                               │ 주소를 담는 변수 선언    │
├──────────────┼──────────────────────────────────────────────┼──────────────────────────┤
│ int* p = &x; │ "p에 x의 주소를 넣는다" / "p가 x를 가리킨다" │ p == x의 주소            │
├──────────────┼──────────────────────────────────────────────┼──────────────────────────┤
│ *p           │ "p가 가리키는 것"                            │ x의 값 (42)              │
├──────────────┼──────────────────────────────────────────────┼──────────────────────────┤
│ *p = 100;    │ "p가 가리키는 것에 100을 넣는다"             │ x == 100                 │
├──────────────┼──────────────────────────────────────────────┼──────────────────────────┤
│ p->m         │ "p가 가리키는 것의 m"                        │ (*p).m과 같음            │
├──────────────┼──────────────────────────────────────────────┼──────────────────────────┤
│ int& r = x;  │ "int 참조 r은 x" / "r은 x의 별명"            │ r과 x는 같은 변수        │
├──────────────┼──────────────────────────────────────────────┼──────────────────────────┤
│ r = 7;       │ "r에 7을 넣는다" (= x에 넣는다)              │ x == 7                   │
└──────────────┴──────────────────────────────────────────────┴──────────────────────────┘

이번 예제(main.cpp)에 적용하면

const std::array buffers = {&inputA, &inputB, &output};
// "buffers는 inputA의 주소, inputB의 주소, output의 주소를 담은 배열"

for (auto* buffer : buffers)
// "buffers에서 포인터를 하나씩 꺼내 buffer에 담는다"
// → 1회차: "buffer가 inputA를 가리킨다"

    createBuffer(bufferSize, *buffer);
    // "buffer가 가리키는 것(= inputA)을 createBuffer에 넘긴다"

bool createBuffer(vk::DeviceSize size, BufferResource& resource)
// "resource는 BufferResource 참조" → "resource는 넘겨받은 inputA의 별명"

    resource.buffer = vk::raii::Buffer(device, bufferInfo);
    // "resource(= inputA)의 buffer에 새 버퍼를 넣는다" → 원본 inputA가 바뀜

void* mapped = resource.memory.mapMemory(0, bufferSize);
// "void 포인터 mapped에 매핑된 메모리의 주소를 넣는다"
// → "mapped가 GPU 버퍼 메모리를 가리킨다"

한 줄 규칙

- &x, T*, *p → "주소", "포인터", "가리킨다"
- T& → "참조", "별명"
